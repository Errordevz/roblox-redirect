DEMO MCP

DEMO MCP is a private developer tool — a Model Context Protocol server with its own browser. Connect your own Roblox account so DEMO can read your profile through Roblox's official OAuth 2.0 APIs.

Connect Roblox account Check connection status

Signing in

  1. "Connect Roblox account" opens apis.roblox.com/oauth/v1/authorize. Roblox hosts the whole sign-in and consent screen.
  2. You approve the scopes openid and profile only.
  3. Roblox returns you to DEMO, which shows the connected username and user id.

What DEMO does

  • Reads only your Roblox user id, username, display name and avatar.
  • Never asks for your password or .ROBLOSECURITY cookie, and never scrapes roblox.com.
  • Keeps tokens on the server, encrypted at rest (AES-256-GCM); never logged or shared.
  • Disconnect any time — tokens are revoked at Roblox and the record is deleted.
